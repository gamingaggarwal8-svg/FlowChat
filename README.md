# FlowChat

**Chat se cash tak.** A working demo for WhatsApp-first textile distributors: customers, suppliers, inventory, stock planning, payment promises and owner-approved follow-ups.

All supplied business data is **synthetic**, fixed as of **14 November 2026**. The synthetic dashboard runs without an API key; connected integrations use server credentials. Numbers are computed in code, not generated by an LLM.

## Start locally

Use Node.js 22 LTS and npm.

```bash
npm ci
npm run dev
```

Open http://localhost:3000. No database, account connection or `.env` file is required for the dashboard.

## Login, visual opening and remembered conversations

Guests now see a dedicated sign-in page with account creation, password reset and an explicit synthetic-demo entrance. The dashboard opens with a clickable graphical workflow; the existing numbers, stock analysis and financial tables follow after scrolling.

AI Copilot saves personal business conversations in Supabase and resumes recent context on a return visit. Current financial facts are recalculated, while past answer evidence remains historical. Disposable caches have a separate cleanup function; saved chats and financial records do not expire automatically. Offline demo history stays in the browser.

Use [GEMINI_SUPABASE_SETUP.md](GEMINI_SUPABASE_SETUP.md) for the shortest end-to-end configuration instructions. Existing installations need the new `202611140003_conversation_memory.sql` migration.

## New integration workflows

- **Import Chats** (`/import-chats`): WhatsApp TXT/ZIP parsing, Gemini structured extraction, exact evidence checks and prepared synthetic cache fallback.
- **Accounting & Documents** (`/accounting`): private Supabase PDFs or local IndexedDB fallback, preview/search/download, invoice extraction/review and CA PDF/CSV summaries. No automatic GST filing.
- **Excel Sync** (`/sync`): real XLSX imports, stable IDs, duplicate prevention, immutable revisions, audit inspection, Microsoft OAuth/OneDrive Sync Now and an authenticated polling-job endpoint.
- **Plans & Billing** (`/pricing`): provisional ₹0/₹499/₹999/custom plans, explicit demo checkout, server-verified Razorpay subscriptions, signed webhooks, history and cancellation.
- **AI Copilot** (`/copilot`): Gemini intent routing and explanations over deterministic ledger/stock facts and saved conversation evidence; reminder drafts connect to the existing approval queue. Offline mode uses labelled deterministic answers/templates.
- **Workspace Settings** (`/settings`): Supabase sign-in, business selection/creation, owner-managed accountant/viewer access and official signed Meta webhook ingestion.

Start with [INTEGRATIONS.md](INTEGRATIONS.md) for exact setup, workbook fields, secrets, provider configuration, security guarantees and remaining limitations. Run the Supabase migration before enabling a connected workspace. Static Sites hosting supports local demo workflows; use the full Next.js server for live integrations.

## What is included

- Overview with receivables, supplier payables, inventory value, open quotes and a next-14-day cash comparison.
- Customer ledger, invoice/payment evidence, payment-promise review and English/Hinglish questions routed to predefined analysis functions.
- Supplier workspace sheet with contacts, credit terms, invoice/payment evidence, delivery commitments, owner promises and CSV download.
- Inventory segmentation by type, fabric, colour, gender/audience and unit; editable local catalog classifications.
- Stock quantity bands: Out of stock, Critical, Low, Adequate, Excess and Unverified.
- Stock-cover scenarios that subtract incoming POs, show indicative top-up costs and flag cash pressure.
- Recharts bars/donuts and graphs that follow inventory filters. Quantities in metres and pieces are never added together.
- Voice-transcript review, `.txt`/`.vtt` import, reviewed local copies, browser microphone transcription where supported, and local audio playback.
- Draft reminder, supplier and stock requests; editable approval queue; bargaining floor-price checks. Nothing is auto-sent.
- Original synthetic CSV/chat data, prepared extraction fixtures, demo guide and test suites.

## Data and fixtures

All source business files are under `data/`:

- Customer chats, invoices, payments, order lines, quotes and product prices.
- `data/suppliers/`: supplier chats, purchase orders/lines, invoices, payments and rate history.
- `data/inventory/`: stock movements and inventory snapshot.
- `data/product_attributes.csv`: additional demo catalog metadata. Missing colours remain Unspecified; garment audience labels are clearly marked demo owner classifications.
- `data/extracted/`: 12 customer and 7 supplier annotation caches. These are prepared fixtures, not proof of a live extraction run.
- `data/expected_metrics.json` and expected extraction files: reference assertions, not calculation inputs.

```bash
npm run seed:cache          # fill missing caches without overwriting existing ones
npm run prepare:operations # regenerate the source snapshot used by static hosting
npx tsx scripts/check-analytics.ts
```

The Next.js page reads `data/` on the server. Its customer import/demo components also support browser-local state. Saved transcripts, catalog edits, imported browser files and approval drafts stay in the browser and are not part of Git history.

## Gemini and the legacy evaluator

The new `/api/chats`, `/api/ai` and document-extraction APIs use the official `@google/genai` SDK and `GEMINI_API_KEY`, with a configurable Flash model, Zod validation, business-scoped cache, database quota and bounded retry. They require a valid Supabase session and workspace role. Read [INTEGRATIONS.md](INTEGRATIONS.md) before using real conversations, including the Google free-tier processing terms.

The original Anthropic implementation/evaluator is preserved separately. Its optional `/api/extract` route now also requires workspace authorisation and quota; the CLI still uses the explicitly configured legacy provider. The requested legacy model `claude-sonnet-5-5` has not been verified with live credentials.

```bash
npm run eval -- sharma_textiles gupta_fabrics
npm run eval
```

Without credentials the legacy evaluator reports NOT SCORED. It never substitutes expected answers for model output. Never commit API keys or real `.env` files.

## Voice limitations

Browser microphone capture depends on SpeechRecognition support, permission and the browser's speech service; it may require internet. It starts only after the user clicks Start microphone. Uploaded audio is playback-only: automatic audio-file transcription is not connected. Reviewed transcript text does not automatically create orders, payment promises or ledger entries.

## Deploy on Vercel

1. Push this folder to your GitHub repository using [GITHUB_PUSH.md](GITHUB_PUSH.md).
2. Import the repository into Vercel and keep the detected Next.js defaults.
3. Build command: `npm run build`. No environment variables are required for the synthetic demo. Configure the live server using `.env.example` and `INTEGRATIONS.md`.
4. Deploy. Start with provider test credentials and verify the authenticated integration flows described in `INTEGRATIONS.md`. Preserve private access for real business data.

For a static dashboard bundle:

```bash
npm run build:demo
```

This creates `dist/`, including its sample-data download. Serve it with any static web server. The static bundle excludes Next.js API routes; use Vercel/Next.js for those. Opening `dist/index.html` directly with `file://` is not supported.

## What is deliberately excluded from the repository package

Installed dependencies (`node_modules/`), `.next/`, generated `dist/`, private hosting identity (`.openai/`), Git history/credentials, real `.env` files and temporary work files. Everything needed to regenerate builds is included, with `package-lock.json` for reproducible installation.

See [DEMO.md](DEMO.md) for the three-minute demo flow. Forecasting, automatic WhatsApp sends, an autonomous Collections Agent tab and a separate Business Case tab are not implemented in this checkout.
